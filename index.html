🕵️ Secret Vault: Terminal Pro-Tips

You've unlocked the forbidden knowledge panel. Here are some secret Linux power-user suggestions:

Tip #1

Fix typos with ^old^new

Made a typo in your last command? Swap words instantly without retyping:

$ apt-get install nginx
$ ^install^remove
Tip #2

Run the previous command as root

Forgot sudo on a long command? Use !! to auto-insert it:

$ systemctl restart nginx
Permission denied.
$ sudo !!
Tip #3

Reuse the last argument with !$

Pass the last argument from your previous command into the next:

$ mkdir -p /var/www/my-site
$ cd !$
Tip #4

Search command history instantly

Press Ctrl + R in your terminal and type to reverse-search every command you've ever run.
