🐧 Dual-Booting Linux: Windows + Linux on One PC

So you've heard about Linux. Maybe your friend keeps talking about Arch. Maybe you've seen people running Ubuntu on ancient laptops. Maybe you just want to find out what all the fuss is about. But there's one problem: You don't want to get rid of Windows.

Good news: you don't have to.

What is dual-booting?

Dual-booting means having two operating systems installed on the same computer. When you turn your computer on, you can choose which one you want to use:

Computer starts ➔ UEFI ➔ Bootloader ➔ Windows OR Linux

You aren't running both at once. You choose one, and that operating system gets control of the computer. Think of it like having two houses on the same block. They're on the same piece of land, but each has its own stuff inside.

⚠️ Before you do anything: Back up anything important. Installing an operating system usually involves changing partitions on your drive. If you select the wrong partition, you can lose data. Use a computer you own and are allowed to modify.

What is actually being changed?

Your computer's SSD or Hard Drive is divided into partitions. It usually starts as one giant undivided space:

[ EFI | Recovery | Windows C: ]

When you install Linux, you shrink the Windows partition to create unallocated space:

[ EFI | Recovery | Windows C: | Unallocated space ]

Linux is then installed into that empty space:

[ EFI | Recovery | Windows | Linux ]

The key point: Linux doesn't need to replace Windows—it sits right alongside it.

Step-by-Step Overview

1. Choose a Linux Distribution

Linux itself is technically the kernel. What people call "Linux" is actually a distribution (or "distro"). Beginner-friendly distros include:

  • Ubuntu: Popular, massive community support.
  • Linux Mint: Perfect for users coming from Windows.
  • Fedora: Clean, modern desktop environment.
  • Pop!_OS: Great for gaming and NVIDIA graphics setup.

2. Prepare a Bootable USB Drive

Download the ISO image for your chosen distro and flash it onto a USB drive using tools like BalenaEtcher or Rufus.

3. Boot from the USB Drive

Plug the USB into your computer and restart. Boot into your motherboard's boot menu (usually F12, F11, Esc, or F9) and choose the USB drive.

4. Try Before Installing

Most desktop Linux installers boot into a live environment first. Test your Wi-Fi, keyboard, mouse, and audio before touching your hard drive.

5. Run the Installer

Select "Install Linux alongside Windows" during setup so the installer automatically sizes and formats the drive safely for you.

6. Restart and Pick Your OS

After installation, restarting will bring up a menu where you select whether to load Windows or Linux.
